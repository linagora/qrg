## Agent skills

### Issue tracker

Les tickets vivent dans les GitHub Issues de `linagora/qrg`, via la CLI `gh`. Voir `docs/agents/issue-tracker.md`.

Vocabulaire par défaut : `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Voir `docs/agents/triage-labels.md`.

### Domain docs

Un seul contexte : `CONTEXT.md` et `docs/adr/` à la racine. Voir `docs/agents/domain.md`.
