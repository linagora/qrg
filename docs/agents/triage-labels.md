# Libellés de triage

Les skills raisonnent en cinq rôles de triage canoniques. Ce fichier fait correspondre ces rôles aux libellés réellement utilisés dans le tracker de ce dépôt.

| Libellé dans mattpocock/skills | Libellé dans notre tracker | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Un mainteneur doit évaluer ce ticket |
| `needs-info` | `needs-info` | En attente d'informations du rapporteur |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Demande une implémentation humaine |
| `wontfix` | `wontfix` | Ne sera pas traité |

Quand un skill nomme un rôle (par exemple « poser le libellé de triage prêt pour un agent autonome »), utiliser le libellé correspondant de cette table.

Modifier la colonne de droite pour suivre le vocabulaire réellement employé.
